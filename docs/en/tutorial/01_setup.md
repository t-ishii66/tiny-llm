# Step 1: Setup and Running

![Setup and Running](../../images/tutorial-01-setup.png)

First, let's get the code running.

---

## 1.1 What You Need

All you need to run this project is **[uv](https://docs.astral.sh/uv/)**.
uv will automatically bring in Python itself and PyTorch as needed.
No GPU is required; tiny-LLM finishes training in a few seconds.

Installing uv:

```bash
# macOS / Linux
curl -LsSf https://astral.sh/uv/install.sh | sh

# Windows (PowerShell)
powershell -c "irm https://astral.sh/uv/install.ps1 | iex"

# Homebrew (macOS)
brew install uv
```

After installing, if `uv --version` shows a version, you're good to go.

> **Why use uv**: it is faster than pip + venv, and it handles everything from Python
> version management to installing dependencies in a single tool.
> There is no need to create a virtual environment by hand, and no `source venv/bin/activate` either.

## 1.3 Running It

```bash
uv run --with torch tiny_llm.py
```

`--with torch` means "temporarily add PyTorch and run this script".
The first time there is a PyTorch download, so you'll wait a little, but from the second time on it starts instantly from the cache.
Even in an environment without Python installed, uv automatically fetches the required version.

> Chapter 5's `tiny_llm_instruct.py` can be run the same way: `uv run --with torch tiny_llm_instruct.py`

## 1.4 How to Read the Output

### The Course of Training

```
epoch   20  loss=1.9469    ← still a nonsense prediction
epoch  200  loss=0.1147    ← an almost perfect prediction
```

- **epoch**: how many times it has gone through the training data
- **loss**: how bad the prediction is (smaller is better). About 2.3 if random, 0 if perfect

### The Generated Result

```
prompt: "the cat sat on"
output: the cat sat on the mat . the dog sat on the log ...
```

- **prompt**: the input text given to the model
- **output**: the text the model generated by predicting one word at a time

Natural English sentences in line with the training corpus are being generated.

> **Note**: build the prompt you pass to `generate()` using only words contained in the training corpus.
> If it contains a word outside the corpus (an out-of-vocabulary token), the current implementation raises an exception.

## 1.5 What Just Happened

In just a few seconds, the following was executed:

1. **Data preparation**: convert the 40-word corpus into numbers and create the training data
2. **Model construction**: initialize a Transformer with about 68,000 parameters
3. **Training**: learn "next-word prediction" over 200 training loops
4. **Generation**: generate text with the trained model

In the next step, we will check the contents of each of these stages with our own eyes.

## (Supplement) Where uv Puts PyTorch

Only read this if you're curious. The PyTorch installed by `uv run --with torch ...` is placed entirely in **a cache directory dedicated to uv**. It writes nothing into the project directory (`./.venv/` etc.), the system Python, or the Homebrew Python.

| OS | Cache location |
|---|---|
| macOS | `~/Library/Caches/uv/` |
| Linux | `~/.cache/uv/` |
| Windows | `%LocalAppData%\uv\cache\` |

- Check the location: `uv cache dir`
- Keep the size down: `uv cache prune` (deletes only old entries)
- Full reset: `uv cache clean`
