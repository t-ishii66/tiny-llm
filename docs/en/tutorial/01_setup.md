# Step 1: Setup and Run

Let's start by running the code.

---

## 1.1 Requirements

The only thing you need is **[uv](https://docs.astral.sh/uv/)** — Astral's modern Python package manager.
uv automatically handles Python itself and PyTorch as needed.
No GPU required; tiny-LLM completes training in seconds.

Install uv:

```bash
# macOS / Linux
curl -LsSf https://astral.sh/uv/install.sh | sh

# Windows (PowerShell)
powershell -c "irm https://astral.sh/uv/install.ps1 | iex"

# Homebrew (macOS)
brew install uv
```

After installing, verify with `uv --version`.

> **Why uv**: faster than pip + venv, and it handles Python version management,
> virtual environments, and dependency installation through a single tool.
> No manual `venv` creation or `source venv/bin/activate` needed.

## 1.3 Run It

```bash
uv run --with torch tiny_llm.py
```

`--with torch` tells uv to add PyTorch ad-hoc for this run.
The first run downloads PyTorch (a few seconds to minutes depending on your connection),
but subsequent runs start instantly from the cache.
You don't even need Python pre-installed — uv will fetch a suitable version automatically.

> **Where packages live**
>
> Anything installed via `--with` lands in uv's **own cache directory**:
>
> - macOS: `~/Library/Caches/uv/`
> - Linux: `~/.cache/uv/`
> - Windows: `%LocalAppData%\uv\cache\`
>
> Nothing is written to your project directory (no `./.venv/`), your system Python, or Homebrew Python.
> Check the location with `uv cache dir`; trim old entries with `uv cache prune`;
> wipe everything with `uv cache clean` when you're done with the project.

> Chapter 5's `tiny_llm_instruct.py` runs the same way: `uv run --with torch tiny_llm_instruct.py`

## 1.4 Reading the Output

### Training Progress

```
epoch   20  loss=1.9469    ← Still mostly random predictions
epoch  200  loss=0.1147    ← Nearly perfect predictions
```

- **epoch**: How many times the model has gone through the training data
- **loss**: How bad the predictions are (lower is better). Random ≈ 2.3, perfect = 0

### Generation Results

```
prompt: "the cat sat on"
output: the cat sat on the mat . the dog sat on the log ...
```

- **prompt**: The input text given to the model
- **output**: Text generated by the model, predicting one word at a time

The model generates natural English sentences consistent with the training corpus.

> **Note**: The prompt passed to `generate()` must consist only of words that appear in the training corpus.
> Including out-of-vocabulary words will cause an exception in the current implementation.

## 1.5 What Just Happened

In just a few seconds, the following was executed:

1. **Data preparation**: Converted a 40-word corpus into numerical form and created training data
2. **Model construction**: Initialized a Transformer with ~68,000 parameters
3. **Training**: Learned to predict "the next word" over 200 training loops
4. **Generation**: Generated text using the trained model
