# Step 1: Setup and Run

Let's start by running the code.

---

## 1.1 Requirements

The only thing you need to run this project is **[uv](https://docs.astral.sh/uv/)**.
uv will automatically provide Python itself and PyTorch as needed.
No GPU required; tiny-LLM completes training in seconds.

Install uv:

```bash
# macOS / Linux
curl -LsSf https://astral.sh/uv/install.sh | sh

# Windows (PowerShell)
powershell -c "irm https://astral.sh/uv/install.ps1 | iex"

# Homebrew (macOS)
brew install uv
```

After installation, if `uv --version` displays a version, you're good to go.

> **Why use uv**: it's faster than pip + venv, and handles everything from Python version management
> to dependency installation in a single tool.
> No need to manually create virtual environments or run `source venv/bin/activate`.

## 1.3 Run It

```bash
uv run --with torch tiny_llm.py
```

`--with torch` means "temporarily add PyTorch and run this script."
The first run takes a moment to download PyTorch, but subsequent runs start instantly from the cache.
Even in environments without Python installed, uv will automatically fetch the required version.

> Chapter 5's `tiny_llm_instruct.py` runs the same way: `uv run --with torch tiny_llm_instruct.py`

## 1.4 Reading the Output

### Training Progress

```
epoch   20  loss=1.9469    ← Still random predictions
epoch  200  loss=0.1147    ← Nearly perfect predictions
```

- **epoch**: How many times the training data has been gone through
- **loss**: How bad the predictions are (lower is better). Random ≈ 2.3, perfect = 0

### Generation Results

```
prompt: "the cat sat on"
output: the cat sat on the mat . the dog sat on the log ...
```

- **prompt**: The input text given to the model
- **output**: Text generated by the model, predicting one word at a time

Natural English sentences consistent with the training corpus are generated.

> **Note**: The prompt passed to `generate()` must be composed only of words contained in the training corpus.
> If it includes words outside the corpus (out-of-vocabulary tokens), the current implementation will raise an exception.

## 1.5 What Just Happened

In just a few seconds, the following was executed:

1. **Data preparation**: Converted a 40-word corpus into numbers and created training data
2. **Model construction**: Initialized a Transformer with ~68,000 parameters
3. **Training**: Learned "next-word prediction" over 200 training loops
4. **Generation**: Generated text using the trained model

In the next step, we'll examine the internals of each stage with our own eyes.

## (Appendix) Where uv puts PyTorch

Only read this if you're curious. PyTorch installed via `uv run --with torch ...` is placed entirely in **uv's own cache directory**. Nothing is written to the project directory (`./.venv/`, etc.), the system Python, or Homebrew Python.

| OS | Cache location |
|---|---|
| macOS | `~/Library/Caches/uv/` |
| Linux | `~/.cache/uv/` |
| Windows | `%LocalAppData%\uv\cache\` |

- Check the location: `uv cache dir`
- Reduce size: `uv cache prune` (deletes only old entries)
- Full reset: `uv cache clean`
